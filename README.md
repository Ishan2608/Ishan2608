## What I'm Building Right Now

**[Artha](https://github.com/Ishan2608)** — A personal financial AI Agent that reads your documents (via OCR), reasons over them using RAG, and gives you grounded, source-backed financial guidance. Built on LangChain, Gemini, and FastAPI.

**Smart System Optimizer** *(in progress)* — Windows task management rebuilt around AI. Instead of just showing you what's running, it tells you what should be running and why.

**AI Agents research** — Specifically interested in agents that can plan across multi-step tasks, use tools, and maintain working memory across a session.
